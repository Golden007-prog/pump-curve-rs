pump-curve-rs

pump.fun bonding curve math in Rust, exact to the lamport

Decode a pump.fun bonding-curve account, derive its address from the mint, and quote buys and sells with the program's own integer rounding: tokens out, SOL in, both fees, and the slippage limits for the buy and sell instructions. Zero dependencies, no_std, no unsafe.

Install

cargo add --git https://github.com/blixvip/pump-curve-rs

Rust 1.70 or newer. Turn off default features for no_std.

Quick start

use pump_curve::{bonding_curve_address, max_sol_cost, BondingCurve, Fees, Pubkey};

// Where the curve lives (pure, no network).
let mint: Pubkey = "DxYWLXgKJpQmfhTG7ikK6oX6oDhxMhN5wCs5BJekpump".parse()?;
let (curve_address, _bump) = bonding_curve_address(&mint)?;

// Fetch that account with your RPC client (getAccountInfo, base64) and decode it.
let data = BondingCurve::fresh(Pubkey::new([1; 32])).to_bytes(); // stand-in for the fetched bytes
let curve = BondingCurve::decode(&data)?;

// Quote. Fees are yours to supply: 95 + 30 bps was pump.fun's published rate in November 2026.
let fees = Fees::new(95, 30);
let buy = curve.buy_exact_sol_in(500_000_000, fees)?;           // spend 0.5 SOL, fees included
let cost = curve.buy_exact_tokens_out(buy.tokens_out, fees)?;
let limit = max_sol_cost(cost.total_sol, 100)?;                  // 1% slippage
println!("{} tokens, {:.2}% of the curve sold", buy.tokens_out, curve.progress_pct().unwrap());

What it does

  • Decodes every BondingCurve layout pump.fun has written (49, 81 and 166 bytes)
  • buy_exact_sol_in, buy_exact_tokens_out, sell_exact_tokens_in in u128 with checked arithmetic
  • Reproduces nine real mainnet trades to the lamport, fees included
  • Price, market cap, curve progress, migration market cap
  • Curve address from the mint, offline (built-in SHA-256 and ed25519 point check)
  • Fees as a parameter, plus pump.fun's market-cap fee-tier rule
