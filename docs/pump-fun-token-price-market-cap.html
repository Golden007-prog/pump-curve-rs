How to calculate a pump.fun token's price and market cap

While a pump.fun coin is on its bonding curve, its price is not set by an order book or a pool: it is two numbers in one account. Read that account and you have the price, the market cap, how far along the curve is, and the market cap at which it will migrate, with one RPC call and no API.

Where the numbers live

Each coin has a bonding-curve account at the program-derived address of seeds ["bonding-curve", mint] under the pump program 6EF8rrecthR5Dkzon8Nwu78hRvfCKubJ14M5uBEwF6P. After an 8-byte discriminator it holds, as little-endian u64s: virtual token reserves, virtual SOL reserves, real token reserves, real SOL reserves and total supply, then a complete flag. Fetch it with getAccountInfo (base64 encoding); the free public RPC serves this.

The formulas

FigureFormula
Price (SOL per token)(virtual_sol / 10^9) / (virtual_tokens / 10^6)
Market cap (SOL)price × total_supply / 10^6 (one billion tokens on a standard coin)
Market cap, exact (lamports)floor(virtual_sol × supply / virtual_tokens), how pump.fun's fee program sizes fee tiers
Progresssold / (sold + real_tokens) with sold = 1,073,000,000 − virtual_tokens (whole tokens)
Migration market capk / end_tokens² × supply with k = virtual_sol × virtual_tokens and end_tokens = virtual_tokens − real_tokens

Use the virtual reserves, not the real ones: the real SOL reserve is what the curve actually holds, but the price comes from the constant product over the virtual pair. The price and market cap only make sense while the curve is active and quoted in SOL. A completed curve has migrated, and its price is on the pool now; a curve quoted in another token has its reserves in that token's units.

For a standard curve the migration market cap works out to the same value from start to finish: 279.9 million virtual tokens remain at the end, so 32,190,000,000 / 279,900,000² × 10^9 ≈ 410.88 SOL. In dollars that moves with SOL's price, which is why a "pump.fun graduation market cap" quoted in USD keeps changing.

In Rust

examples/price_market_cap.rs decodes a real bonding-curve account captured from mainnet, computes the figures by hand, and checks them against the crate:

fn main() -> Result<(), Box<dyn std::error::Error>> {
    // A real SOL-quoted pump.fun curve read from mainnet (tests/fixtures/curve_sol_active.b64).
    let data = base64(include_str!("../tests/fixtures/curve_sol_active.b64"))?;
    let curve = BondingCurve::decode(&data)?;

    // By hand: price = virtual SOL / virtual tokens, both in whole units.
    let sol = curve.virtual_sol_reserves as f64 / LAMPORTS_PER_SOL as f64;
    let tokens = curve.virtual_token_reserves as f64 / TOKEN_UNIT as f64;
    let price = sol / tokens;
    // Market cap = price x total supply (one billion tokens on a standard coin).
    let supply = curve.token_total_supply as f64 / TOKEN_UNIT as f64;
    let market_cap = price * supply;
    println!("by hand:  price {price:.12} SOL, market cap {market_cap:.4} SOL");

    // The crate gives the same figures, and returns None when they do not apply (migrated, or not priced in SOL).
    let price_c = curve.price_sol().ok_or("not priced in SOL")?;
    let cap_c = curve.market_cap_sol().ok_or("not priced in SOL")?;
    println!("crate:    price {price_c:.12} SOL, market cap {cap_c:.4} SOL");
    assert_eq!(price, price_c);
    assert_eq!(market_cap, cap_c);

    // Exact integer market cap in lamports, the way pump.fun's fee program computes it for fee tiers.
    let cap_lamports = curve.market_cap_lamports(TOKEN_TOTAL_SUPPLY)?;
    println!("exact:    market cap {cap_lamports} lamports");

    // How far along the curve is, and the market cap at which it completes and migrates.
    let progress = curve.progress_pct().ok_or("no progress for this curve")?;
    let migrates_at = curve.migration_market_cap_sol().ok_or("no migration cap")?;
    println!("progress: {progress:.2}% of the curve sold, migrates at {migrates_at:.2} SOL market cap");

    // In dollars: multiply by SOL's price from any source you trust. 140.0 is a placeholder, not a quote.
    let sol_usd = 140.0;
    println!("at ${sol_usd} per SOL: market cap ${:.0}", cap_c * sol_usd);

    // A brand-new coin, for comparison.
    let fresh = BondingCurve::fresh(pump_curve::Pubkey::default());
    println!(
        "new coin: price {:.12} SOL, market cap {:.2} SOL, migrates at {:.2} SOL",
        fresh.price_sol().unwrap_or_default(),
        fresh.market_cap_sol().unwrap_or_default(),
        fresh.migration_market_cap_sol().unwrap_or_default(),
    );
    Ok(())
}

A live coin, from its mint

Solana RPC is HTTPS, which Rust's standard library cannot speak on its own, and the crate stays dependency-free. examples/live_quote.rs splits the job: it derives the curve address from the mint offline and prints the request, curl fetches it, and the example reads the JSON from stdin, checks the owner is the pump program, and prints the figures and a quote.

$ cargo run -q --example live_quote -- 5RhfKrSQm6p7cbqLgBbpNYvxpz8rXXnofPotjfKqpump
curve account: 4Q4BXxsXDwwcVzFY3AzbB71qZJ3c41Rcq5c2SbTmgH4T
run:

curl -s https://api.mainnet-beta.solana.com -H 'content-type: application/json' -d '{"jsonrpc":"2.0","id":1,"method":"getAccountInfo","params":["4Q4BXxsXDwwcVzFY3AzbB71qZJ3c41Rcq5c2SbTmgH4T",{"encoding":"base64"}]}' | cargo run -q --example live_quote -- 5RhfKrSQm6p7cbqLgBbpNYvxpz8rXXnofPotjfKqpump -

Run that curl with 0.5 added after the final - (the SOL to quote; the default is 0.1) and you get, for that coin on 2026-11-17:

Mayhem-mode coins, completed curves and curves quoted in another token are detected and reported instead of quoted. In a real program, fetch the bytes with the HTTP client you already use and call BondingCurve::decode.

Same answer as the JavaScript version

If you also run the JavaScript pump-curve package, examples/cross_check.mjs decodes the same account bytes in both and compares price, market cap, progress and migration cap. On five curves (three from mainnet, two synthetic) they agree to within 10-9 relative.
